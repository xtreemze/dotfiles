xtreemze / dotfiles

A portable terminal environment from one command.

Start from a safe public baseline. GNU Stow remains the deployment authority; GitHub authentication can then unlock the private machine and identity configuration without exposing it here.

Install

The public bootstrap installs safe packages first, ensures GitHub CLI is available, and asks you to authenticate when needed. Authorized accounts then hand off to the private xtreemze/.dotfiles installer; everyone else receives the public Stow configuration.

Setup boundary

public dotfiles
  → safe packages
  → GitHub CLI
  → gh auth login
      ├─ private access → ~/.dotfiles → private installer
      └─ no access      → public Stow configuration

The public checkout is staged separately under ~/.local/share/xtreemze/dotfiles-public, leaving ~/.dotfiles reserved for the authenticated private repository.
