# Package icon sources

This directory vendors selected project marks for the public package catalog.

## Simple Icons

Selected marks are sourced from the Simple Icons project:

- https://github.com/simple-icons/simple-icons
- Repository license: CC0-1.0
- Brand names and logos remain trademarks of their respective owners.
- Individual icon licensing can differ; Simple Icons recommends checking its current metadata and disclaimer before reuse.

## Upstream project artwork

Additional SVG artwork is copied directly from the upstream project repositories:

- zoxide: `ajeetdsouza/zoxide` — `contrib/logo-dark.svg`
- btop: `aristocratos/btop` — `Img/icon.svg`
- Fastfetch: `fastfetch-cli/fastfetch` — `src/logo/logo.svg`
- lnav: `tstack/lnav` — `docs/assets/images/favicon.svg`

The website uses a project mark only when there is a suitable, distinct asset. Packages without one use a generated monogram instead of borrowing an unrelated logo.
